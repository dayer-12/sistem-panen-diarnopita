# Sistem Penghitung Hasil Panen

## Deskripsi
Program sederhana menggunakan Python untuk menghitung total hasil panen dan total hasil panen setelah diberikan diskon 10%.

## Cara Menjalankan Program
1. Pastikan Python sudah terinstal.
2. Buka terminal pada folder proyek.
3. Jalankan perintah berikut:

```bash
python panen.py
